# 读懂这个人

写信之前，先把记录从头读一遍。结构摘要说的是这个人怎么看，这一步找的是对方**没打算告诉你的东西**。

所有结论都是猜想。没有研究证明一次罗夏能读出潜意识（元分析见 report.md）。可以说「这次记录里有这样的痕迹」，不能说「你潜意识里是这样」。下面的顺序分析和主题分析是罗夏解读的传统做法（Exner、Schafer，来自记忆，没有对照原著），证据弱于结构变量，所以只进「水面下」这一章，并且都要给出另一种解释。

## 步骤

1. **读全部。** `ror data --full` 和 `ror signals`。不要只看摘要。
2. **逐张走一遍。** 每张问自己：第一反应是什么？后面的回应和第一个是什么关系？这张的停顿、转动、圈画和其他张比怎么样？写一句话，这就是 `plateNotes`。
3. **找重复。** `signals` 只能抓到字面相同的词和一部分意象。你要找换了说法的同一件事：「隔着」「雾」「听不见」「喊话」说的可能是同一件事。
4. **看顺序。** 刺激的画面（受伤、对抗、血和火）后面接的是什么？每张的最后一个回应和第一个比，是更稳了还是更散了？彩色图一出现（第 II、VIII 张）发生了什么？
5. **看缺席。** 十张图里从没出现什么？没有人、没有动作、不用颜色、只看局部、从不转动。一张没有回应的图也是回答。
6. **看对照。** 这几组最容易出东西：
   - 选图时说的理由，和当初看那张图时说的话
   - 说父亲、母亲时用的词，和其他图上反复出现的词
   - 带来的问题，和图上的画面
   - 嘴上说的范围，和手实际圈的范围
   - 说得轻描淡写的地方，和停得最久的地方
7. **处理线索。** 每条 `weight: high` 都要处理：写进 `undercurrents`，或者放进 `dismissed` 写明理由。第一张开口慢多半只是还不熟悉，这种可以放掉。没有理由的不能放。
8. **写之前排个序。** 留下最能让这个人停下来想一想的 3–5 条，不求全。

## 一条线索怎么写

```
saw    只写发生了什么，能在记录里查到。第四张你说「头在很远的地方」，后来选代表父亲的图也选了它，理由是「离我有点远」。
maybe  写成猜想。距离可能不是你对这张图的印象，==像是你一开始就带着的一把尺子==。
other  另一种同样说得通的解释，要真的说得通。这张图从下往上看本来就显得遥远，这句话可能只是在说图。
ask    把判断交还给对方。「有点远」这三个字，你还会用在谁身上？
```

父亲和母亲两题：只说对方怎么说、用了什么词，不判断真实的父母，不用「第四张是父亲图」这类传统说法。

对方在安全暂停里说的话不进入任何线索，脚本已经排除，你也不要引用。

## 基本信息怎么用

年龄、学历、职业是读懂这个人的语境，不是评分依据。这里没有常模，不和任何人比。

| 信息 | 研究怎么说 | 怎么用 |
|---|---|---|
| 成年人的年龄 | 没有发现可靠的关联 | 只当生活阶段的背景 |
| 未成年人的年龄 | 随年龄增长，知觉更常规，不合逻辑的表达更少 | 不把不常规、跳跃读成问题，不标 `strong` |
| 学历 | 受教育年限和复杂度、措辞细腻、综合、应对资源相关 | 不把说得复杂、连得多读成能力强，也不把说得简单读成能力弱 |
| 职业 | 没有查到直接证据 | 只帮你理解内容，比如护士说伤口可能只是日常 |
| 昵称 | | 称呼对方 |

上表的研究来自搜索摘要（Meyer 等 2015，R-PAS 2018 青少年常模更新），没有读过全文。

可以写「你是护士，伤口对你可能是日常」。不能写「以你的学历」「你这个年纪」「同龄人」，校验门会拒绝。
