# 编码

给每条回应写一条，存成 JSON 数组。脚本校验字段并算出结构摘要，你不要自己算。

```json
{
  "id": "r2",
  "loc": "D", "space": false,
  "dq": "+",
  "det": ["Mp", "FY"],
  "fq": "o",
  "pair": false,
  "content": ["H", "Cg"],
  "pop": false,
  "z": "ZA",
  "special": ["GHR"],
  "evidence": "手往上；这块浅一点，所以像纱"
}
```

`evidence` 必填，引用用户说的原话：编码的依据必须是对方说出来的，不是你看图看出来的。

## 顺序

一条回应按这个顺序过一遍，原话和询问都算：

1. **动词。** 飞、站、笑、抬、拉、对着看，这些都是动作。人或拟人记 `M`，动物记 `FM`，物体记 `m`。询问时没有再提，也算。
2. **颜色和明暗。** 说了红、暖、黑黑的，并且它帮助构成了这样东西，就要记。只用来指位置（「红色那块」）不算。
3. **质感、距离、透明、倒影。** 毛茸茸、很远、像纱、水面，各有对应的决定因子。
4. **内容。** 提到的都写上：抬锅是 `H, Hh`，穿靴子是 `H, Cg`。有对应代码就不用 `Id`。
5. **形状。** 上面都没有才记 `F`。`F` 不和其他决定因子并列，有其他决定因子时形状由它自带（`FC`、`FT`）。
6. **形状质量。** 最后判断，只看形状贴合程度。

确实说不清才按更保守的编码。

以下表格来自记忆，没有对照 Exner 原手册。报告附录已如实写明。

## 位置 loc

| 值 | 含义 |
|---|---|
| `W` | 用了整个墨迹 |
| `D` | 常见局部 |
| `Dd` | 少见局部 |
| `space: true` | 用到了空白。`space`、`pair`、`pop` 只能是 `true` 或 `false`，字段名写错会被拒绝 |

`stroke` 事件的 `geo.locationHint` 和 `geo.nearRegion` 只是几何提示，按对方说的为准。

## 发展质量 dq

| 值 | 含义 |
|---|---|
| `+` | 两个以上物体有关联，至少一个有明确形状 |
| `o` | 一个有明确形状的物体 |
| `v/+` | 两个以上物体有关联，都没有明确形状 |
| `v` | 没有明确形状 |

## 决定因子 det

可以有多个（混合）。

| 类 | 值 | 对方会说的 |
|---|---|---|
| 形状 | `F` | 只提形状 |
| 人的动作 | `Ma` `Mp` | 人或拟人在动；a 主动，p 被动 |
| 动物动作 | `FMa` `FMp` | 动物在动 |
| 无生命动作 | `ma` `mp` | 物体在动、爆炸、飘 |
| 彩色 | `FC` `CF` `C` `Cn` | 形状为主 / 颜色为主 / 只有颜色 / 只说出颜色名 |
| 无彩色 | `FC'` `C'F` `C'` | 黑、白、灰被当作颜色用 |
| 质感 | `FT` `TF` `T` | 毛茸茸、光滑，摸起来 |
| 纵深 | `FV` `VF` `V` | 深浅造成的距离 |
| 浓淡 | `FY` `YF` `Y` | 深浅造成的朦胧、透明 |
| 形状纵深 | `FD` | 靠大小或遮挡造成的距离 |
| 反射 | `Fr` `rF` | 倒影、镜子 |

## 形状质量 fq

本 skill 没有常模表。按形状贴合程度判断，并诚实地少用 `+`。

| 值 | 判断 |
|---|---|
| `+` | 形状说得特别精细，并且确实贴合 |
| `o` | 很多人会这样看，形状合理 |
| `u` | 少见，但形状说得通 |
| `-` | 形状明显对不上 |
| `none` | 没有用到形状（`C`、`T`、`Y` 这类） |

## 内容 content

`H` 人，`(H)` 虚构的人，`Hd` 人的局部，`(Hd)`，`Hx` 人的体验，`A` 动物，`(A)`，`Ad`，`(Ad)`，`An` 解剖，`Art` 艺术，`Ay` 人类学，`Bl` 血，`Bt` 植物，`Cg` 衣物，`Cl` 云，`Ex` 爆炸，`Fi` 火，`Fd` 食物，`Ge` 地理，`Hh` 家居，`Ls` 风景，`Na` 自然，`Sc` 科学，`Sx` 性，`Xy` X 光，`Id` 其他。

## 从众 pop

| 图 | 内容 | 位置 |
|---|---|---|
| I | 蝙蝠或蝴蝶 | 整体 |
| II | 动物 | 两侧黑色部分 |
| III | 人形 | 两侧人形部分 |
| IV | 人或类人 | 整体或下部 |
| V | 蝴蝶或蝙蝠 | 整体 |
| VI | 兽皮 | 整体或下部 |
| VII | 人头或人脸 | 上部 |
| VIII | 动物 | 两侧粉色部分 |
| IX | 类人 | 上方橙色部分 |
| X | 螃蟹或蜘蛛 | 两侧蓝色部分 |

## 组织 z

把分值类型告诉脚本，脚本查表：`ZW` 整体且 DQ 为 + 或 o 或 v/+；`ZA` 相邻部分有关联；`ZD` 不相邻部分有关联；`ZS` 用到空白并与墨迹结合。不符合就写 `null`。

## 特殊分 special

`DV` `DV2` 用词偏离，`DR` `DR2` 离题，`INCOM` `INCOM2` 不协调的合成，`FABCOM` `FABCOM2` 不可能的关系，`CONTAM` 融合，`ALOG` 牵强的逻辑，`PSV` 重复，`AB` 抽象，`AG` 攻击，`COP` 合作，`CP` 色彩投射，`MOR` 损坏或悲伤，`PER` 个人经历，`GHR` `PHR` 人类表征好或差。

## 旋转和缩放

- 旋转是位置记号（`∧ > ∨ <`，脚本记在每条回应的 `orientation`），记录它，不因转动本身加减分。
- 缩放和移动没有常模。只描述，不计分，不解释，不写进报告的判断。
- 反应时看 `rtBasis`：`vad` 最准，`typing` 和 `transcript` 偏慢，不同依据之间不要比较。
