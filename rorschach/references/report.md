# 写信

读者是刚看完十张图的这个人。写完对方应该能说出：这份报告从我说过的哪句话看到了什么，我接下来可以试什么。读到某一句时，对方应该停一下，心想「你怎么知道」。

动笔前先走完 [reading.md](reading.md)。

结构和语气可以参考 `scripts/test/fixture.mjs` 的 `NARRATIVE_FOR`（虚构人物），不要沿用它的句子：换一个人，开头、证据和收尾都应该完全不同。每一句都要能回答「这句为什么只对这个人成立」。

对方在安全暂停里说的话，不引用、不分析，也不写进图版小注和画像。说过这类话时，在信的结尾加一两句关心，不提原话，并写上全国心理援助热线 12356。

## 文件结构

```json
{
  "to": "小林",
  "seen": { "text": "别人只看墨的地方，你点了一盏灯。", "evidence": [{ "response": "r14", "quote": "中间的空白像一盏灯" }] },
  "type": { "note": "这个墨型在这次记录里是什么样，用对方自己的话", "evidence": [{ "response": "r5", "quote": "..." }, { "response": "r13", "quote": "..." }] },
  "takeaways": [{ "text": "读完最该记住的一件事，不超过 40 个字", "evidence": [{ "response": "r9", "quote": "..." }] }],
  "undercurrents": [{

  "share": ["三行短句", "每行不超过十八个字", "可以被别人看到"],
  "closing": "最后一句",
  "signature": "陪你看完这十张的 AI"

```

回应达到 8 条时，`seen`、`type`、正好三条 `takeaways`、`title`、三条以上 `glance`、两条以上 `sides`、三行 `share`、每张有回应的图的 `plateNotes` 必填。`undercurrents` 回应达到 14 条时 3–5 条，8 到 13 条时至少 1 条。

- `seen` 不超过 30 个字，放在报告最前面。它是整份报告最重要的一句话，写法见下面「让人觉得被懂」。
- `type.note` 只写这次记录里的具体样子。墨型的名字、比例和固定文案脚本会印，不要重复。名字可以提，但只能是这个人自己的墨型或镜像型。
- `takeaways` 用普通人的话说结论，不用术语。
- `plateNotes` 要用上这张图上对方说过的词，不能写成通用的话。
- 重点用 `==这样==` 标记，每段最多两处，每处不超过 24 个字；`letter` 至少两处。`title`、`glance`、`share` 不能标。
- `letter` 和 `saw` 里的「」只能放对方的原话，`letter` 至少引用三句。

- `title` 不超过 12 个字，出自这个人的一条原话，是一个比喻，和墨型无关。
- `glance` 每条不超过 10 个字，每条对应一个 domain。
- `sides` 写同一件事的两面，光和影都要有证据，别写成优点和缺点各列一条。
- `share` 和 `title` 印在报告封面，对方截图时可能带上：不放带来的问题、父母题的理由和安全话题。真正的分享卡由脚本生成，只有墨型和仓库链接，不含这些内容。
- `choices` 是小注。对方没回答的题不写。选图时说「看不出来」这类原话报告已经照原样显示，小注不用重复。

## 校验门会拒绝

| 规则 | 原因 |
|---|---|
| 引文不是该回应或该选择的原话 | 证据必须可回查 |
| 每条画像少于两条证据，或都来自同一张图 | 单张图不足以下判断。回应不到 8 条时放宽：画像 1 条起、覆盖 1 个 domain、每条 1 条证据；只有一张图有回应时不要求两张图 |
| 画像少于 3 条或多于 7 条，覆盖少于三个 domain | 避免只讲一面 |
| 回应不足 14 条却标 `strong` | 记录太短 |
| 诊断词（抑郁症、人格障碍……） | 这不是诊断 |
| 万能话术（「你内心深处」「其实你」……） | 放在谁身上都成立 |
| 测不出来的说法（MBTI、智商、依恋类型、百分位、匹配度、概率、薪资……） | 这份记录得不出这些 |
| 对父母或童年下判断（原生家庭、童年创伤、「你的父亲很……」） | 说的是图给对方的感觉，不是对家人的判断 |
| 引用安全暂停里的话 | 这些话说的是这个人，不是图 |
| 分享内容用了带来的问题、父母题理由或安全话题的原话 | 分享卡会被别人看到 |
| 对没回答的题写小注 | 没有证据 |
| 置信度超过该 domain 上限 | 见下表 |
| 「你潜意识里」「被压抑」「防御机制」「这说明你」「一定是」 | 这份记录只能给出线索 |
| 「你应该」「你需要」「建议你」「问题在于」 | 说教不会让人觉得被懂 |
| 「相信自己」「你值得」「拥抱自己」「疗愈」「宇宙」 | 谁都能说 |
| 按年龄、学历、职业下判断或和人比（「同龄人」「高学历」「作为一名」） | 没有常模，只能当语境 |
| 未满 18 岁却标 `strong` | 知觉还在发展，没有对应参照 |
| `weight: high` 的线索既没写进 `undercurrents`，也没在 `dismissed` 里说明 | 不能跳过显眼的东西 |
| `maybe` 没写成猜想，`other` 只是换句话再说一遍，`ask` 不是问题 | 留给对方判断 |
| 一条 `undercurrents` 的证据只来自一张图 | 单张图不足以下判断 |
| `letter` 里「」的内容不是对方的原话 | 引用必须真实 |
| 出现别人的墨型名 | 写错了人 |

## 证据等级

上限依据 Mihura 等 2013 年元分析：外部标准相关 r = .27（k = 770），自评相关 r = .08（k = 386）；认知知觉类最强，Color Projection、Egocentricity Index、Isolation Index 最弱。所以对方觉得「不像我」很正常，报告要留出这个余地。

| domain | 看什么 | 上限 |
|---|---|---|
| `processing` | W : D : Dd、Zf、Zd、DQ | strong |
| `mediation` | X+%、XA%、X-%、P | strong |
| `ideation` | M、a : p、WSum6 | strong |
| `affect` | FC : CF+C、Afr、混合、C' | moderate |
| `control` | D、AdjD、EA、es | moderate |
| `interpersonal` | COP、AG、GHR : PHR | tentative |
| `self` | MOR、Fr、FD | tentative |

没有常模表，不写百分位，不说「高于常人」。可以比较这个人自己的前后和各张之间。

## 让人觉得被懂

这是这份报告最要紧的事。被懂的感觉不来自好听的话，来自**对方发现你真的看过、记得、想过**。

**`seen` 这一句：** 用对方自己的画面，说一件对方自己可能没注意到的事。

| 这样写 | 不要这样写 |
|---|---|
| 别人只看墨的地方，你点了一盏灯。 | 你是一个内心有光的人。 |
| 你把最远的那个人，放在了最大的那张图上。 | 你渴望与他人建立连接。 |

**开头。** 第一句不写「今天你看了十张墨迹」。从一个小时刻开始：「第九张你先说『说不上来』，停了一下，还是接着看下去了。这一停我记住了。」

**不用转场词。** 不写「有意思的是」「值得注意的是」，直接说那件事。

**肯定一个动作，不肯定一个人。** 不写「你很勇敢」。写「第九张你说看不出来，还是把它看完了」。

**把习惯说成它帮过什么。** 拖延、回避、话少，先说它替对方做了什么，再说代价，都用猜想的语气。不写缺点，不用「但是」把前一句否掉。

**不急着给答案。** 最打动人的地方往往是一个问题，不是一个结论。

**短句，留白。** 一段里只放一件事。不抒情，不排比。

**写完做两个检查：** 把名字换成别人，这句还成立吗？成立就重写。对方读到这句，会不会想说「你怎么知道」？不会就再想想。

## 怎么写

信的结构借鉴 Finn 的治疗性评估，由近及远：

1. **对方已经知道的。** 开头说对方一听就点头的事，用对方的原话。
2. **能换个角度看的。** 对方知道这件事，但你给出新的说法。
3. **对方可能不同意的。** 放到最后，写成问题或猜想，交给对方判断。

几条做法：

- 每个判断都紧跟它的来源：「第七张你在空白里看到一盏灯」，再说你的看法。
- 带来的问题要正面回答，答不了就直说答不了，再说这份记录能提供什么。
- 写行为，不写性格标签。「你五次用上了整张图」好过「你是一个有大局观的人」。
- 少用「这说明你……」。把看到的摆出来，再说你怎么想，留出对方不同意的余地。
- 父母两题只写对方说了什么、这张图给了什么感觉，不要推到真实的家人身上。
- `invitations` 是这周就能做的小事，不是建议清单。
- `closing` 用对方说过的一个画面收尾，不做总结。
- 语气是坐在对面的朋友。不夸张，不安慰过头，不用术语；术语只出现在附录。
